Transfer method tradeoffs

Move: frees download space immediately but removes the original source copy.

Copy: keeps the original download intact but doubles storage use.

Hardlink: uses no extra data space but requires source and destination on the same filesystem.

Symlink: is flexible, but the original file must remain available for the link to keep working.

Current posture

The library destination and import handoff are both active control points.

A path mistake here affects every import and post-processing job. Review it carefully any time storage is moved, a container mount changes, or download clients are reconfigured.
